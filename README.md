# KIET Attendance Calculator 📊

An open-source browser extension for KIET students to calculate, track, and simulate attendance on the cybervidya portal.

## 🚀 Quick Download (No Account Required)
To use this extension without using Git or a GitHub account:
1. Click the green **"Code"** button at the top of this page.
2. Select **"Download ZIP"**.
3. Extract the ZIP file to a folder on your computer.

## 🛠️ How to Install
1. Open Microsoft Edge (or Chrome).
2. Go to `edge://extensions` (or `chrome://extensions`).
3. Toggle **Developer mode** to **ON**.
4. Click **Load unpacked**.
5. Select the folder you just extracted (the one containing `manifest.json`).

## 💡 Key Features
* **Auto-Scraper**: Automatically clicks all "eye" buttons to get your detailed attendance.
* **Leave Planner**: Calculates exactly how many classes you can skip while staying above 75%.
* **Goal Tracker**: Tells you how many more classes you need to attend to hit your target.
* **Data Log**: Opt-in to share attendance trends to help us improve calculations.
